# Hồ sơ Từ Linh – WORDCLASH

Nguồn hồ sơ chính thức cho linh vật. Script `seeds/seed_mascots.py` đọc file này để điền các trường hồ sơ.
Định dạng: mỗi linh vật một mục `## #<mã> · <Tên>`, bên dưới là các dòng `- khóa: giá trị`.
Các khóa hợp lệ: birthday_text, hometown, personality, likes, dislikes, favorite_word, catchphrase, bio.
